# Repository Working Agreement

- Maintainer attribution: hyz. Keep upstream licenses and third-party notices.
- This repository distributes the framework only. Never commit user memories,
  transcripts, databases, credentials, local service settings, logs or backups.
- Treat data under user home directories as private runtime state, not source.
- Do not automatically commit, push, publish releases or update GitHub after
  local edits. The maintainer must explicitly request each upload.
- README documents installation and usage. Do not add release announcements or
  version-change descriptions unless explicitly requested.
- Do not claim IDE collection or context injection works based only on a direct
  hook-handler test; verify actual host execution separately.
